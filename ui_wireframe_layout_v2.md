# UI Layout Wireframe Description

Berikut adalah representasi struktur tata letak (wireframe) dari gambar UI dalam bentuk plaintext / ASCII Art Markdown:

```text
+----------------------------------------------------------------------------------------------------+
| HEADER MENU(FILE DAN YANG LAIN)                                                             [logo] |
+-----------------------+----------------------------------------------------+-----------------------+
| EKSPLORE(FOLDER)  [=] |                                                    | CHAT AREA             |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                MAIN CONTENT / EDITOR               |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    |                       |
|                       |                                                    | +-------------------+ |
|                       |                                                    | |     CHAT BOX      | |
|                       |                                                    | +-------------------+ |
+-----------------------+----------------------------------------------------+-----------------------+
|                       (  MAIN MENU(KNOWLEDGE) DAN YANG LAIN  )                                     |
+----------------------------------------------------------------------------------------------------+
```

---

## Rincian Komponen Layout

1. **Header (Bagian Atas)**
   - **Teks Left/Title:** `HEADER MENU(FILE DAN YANG LAIN)`
   - **Elemen Kanan:** Logo lingkaran (`logo`)

2. **Panel Utama (Tengah)**
   - **Sidebar Kiri:**
     - Label: `EKSPLORE(FOLDER)`
     - Icon: Toggle / Sidebar icon `[=]`
   - **Area Tengah (Workspace/Editor):**
     - Area kosong utama untuk menampilkan konten/file/editor.
   - **Sidebar Kanan:**
     - Label Atas: `CHAT AREA`
     - Input Box Bawah: Form/Tombol terbungkus kapsul `CHAT BOX`

3. **Footer (Bagian Bawah)**
   - Baris menu melengkung/kapsul lebar bertuliskan: `MAIN MENU(KNOWLEDGE) DAN YANG LAIN`
