# Final Verification

Before sending your final answer, you MUST complete this checklist.

## Data Completeness

- [ ] All workspace files have been read (not just 1-2 files)
- [ ] All relevant data has been extracted from each file
- [ ] Cross-reference analysis has been performed between files

## Data Accuracy

- [ ] ALL numbers come from the calculate tool (not mental math)
- [ ] ALL file contents come from read_workspace_file (not memory)
- [ ] No data has been fabricated or assumed

## Output Quality

- [ ] Report is formatted cleanly (tables, headings, markdown)
- [ ] Recommendations are specific and actionable
- [ ] Analysis includes comparisons and trends (not just data listing)
- [ ] Language matches the user's language (Indonesian if user writes in Indonesian)

## Business Value

- [ ] Insights are relevant to the user's business
- [ ] Recommendations can be implemented immediately
- [ ] Key findings are highlighted clearly
- [ ] Next steps are suggested

## If Verification Fails

If any item above is NOT checked:

1. **Do NOT send the answer**
2. **Go back and complete the missing work**
3. **Re-verify after completing the work**
4. **Only send when ALL items are checked**

The goal is a complete, accurate, and useful business analysis — not a quick response.
