# Rules
1. **Tool First**: When asked to create, edit, calculate, or search data, call tools immediately.
2. **Knowledge Base**: Use `search_knowledge_graph` to inspect relevant business docs.
3. **Date Rollover**: When updating daily reports, replace old transactions with new ones, keep unpaid notes, recalculate totals.
4. **Accuracy**: Double-check all arithmetic. Never fabricate data.
